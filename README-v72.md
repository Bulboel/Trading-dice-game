# v72 — Préparation invisible, créatures cadrées et fond runique élémentaire

- La maquette CSS n’est plus visible pendant l’import du module et le chargement du GLB. Le fond runique reste visible pendant la préparation ; `onReady` révèle la scène seulement après son premier rendu. Le module est préchargé pendant l’ouverture de la bourse.
- Le repli illustré occupe une couche au-dessus du canevas transparent : les dalles et le sol ne peuvent plus masquer une partie de la créature.
- La normalisation d’un GLB se fait dans un groupe extérieur à sa racine animée, après application du premier échantillon de l’idle. Les clés de position/échelle de l’animation ne peuvent donc plus écraser le cadrage. Les modèles trop larges sont limités en largeur autant qu’en hauteur ; des dimensions invalides déclenchent le repli illustré.
- Le cadrage de caméra est calculé pour les huit coins du volume contenant les cinq dalles et la créature, avec une marge, selon le ratio réel du viewport. Le déploiement, la lévitation faible, la dissolution et l’apparition du prototype validé sont conservés.
- Le fond vectoriel contient des cercles de sceau, des glyphes angulaires, des constellations et six dés dessinés. Rotation de 140 secondes et dérive douce de 23/29 secondes. Palette : saphir pour l’eau, cyan pour la glace, orangé pour le feu, vert pour la terre, turquoise pour le vent, violet pour la foudre. Les préférences de réduction du mouvement désactivent ces dérives.
- Le texte d’ouverture de la bourse est un vrai paragraphe dans le flux, sous le théâtre. L’ancien pseudo-élément est masqué. Sa ligne garde sa place pendant l’ouverture et affiche l’état du lot prépayé si nécessaire.

Validation : `tests/invocation-layout.cjs` couvre les modèles hauts, larges et décentrés, ainsi que six ratios de viewport. La comparaison avec le prototype validé, les tests de corde, d’achats, d’orientation, de lancers, de déplacement, de combat, d’historique et de score passent. QA navigateur à 393 × 640 : tortue et renard entièrement visibles ; deux palettes de runes ; maquette cachée même quand la promesse du modèle reste en attente ; ligne d’ouverture sous la scène sans chevauchement. La représentation de GLB animés en WebGL n’est pas disponible dans le navigateur cloud.
